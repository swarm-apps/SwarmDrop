本政策适用于 SwarmDrop 应用及官方网站。SwarmDrop 是开源的设备间文件传输工具，不要求注册 SwarmDrop 账户。云盘接入是可选功能，仅在提供该功能的版本中、由你主动连接账户并选择云盘作为保存位置后启用。

## 设备间传输与本地数据

设备身份、配对记录、设置、传输历史及收件记录保存在你的设备上。传输时，收发设备会交换设备标识、显示名称、文件名、大小、校验值及连接所需的网络信息。请只与可信设备配对。

设备间的文件传输经过端到端加密。引导节点帮助发现设备；需要中继时，中继节点转发加密数据，并可能处理建立连接所需的 IP 地址等网络信息，不能读取传输中的文件内容。接收后的本地文件不由 SwarmDrop 额外进行静态加密。

SwarmDrop 不设置集中式用户数据后台，不在应用中接入广告或行为分析服务。诊断日志保存在本机；若你主动提交日志或问题报告，请先检查并移除个人信息。

## 可选 Google Drive 接入

连接 Google Drive 时，授权在 Google 的页面中完成。SwarmDrop 不接收或保存你的 Google 密码。应用请求 `https://www.googleapis.com/auth/drive.file` 权限，用于创建、读取及管理由 SwarmDrop 创建，或由你明确向应用开放的 Drive 文件；该权限不提供对整个云盘的任意访问。

OAuth 访问令牌、刷新令牌和你提供的客户端配置保存在本机应用数据目录，供续期和调用 Google API 使用，不上传到 SwarmDrop 运营方的服务器。桌面版使用受文件权限保护的本地文件保存这些凭证；它们仍可被以你的操作系统身份运行的进程访问。请保护你的设备和系统账户。

当你把 Google Drive 选为接收文件的保存位置时，文件先在接收设备上暂存，再通过 HTTPS 上传到你的 Drive。Google 会收到文件内容、文件名、目录以及完成传输、校验和恢复所需的元数据，包括设备标识、传输标识和校验值。设备间的端到端加密不延伸到云盘静态存储；上传后由 Google 按其服务条款和隐私政策处理文件。

### Google API 用户数据的使用限制

SwarmDrop 对从 Google API 获得的信息的使用及向其他应用的转移遵守 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)，包括其中的 Limited Use 要求。

Google 用户数据仅用于你请求的文件保存、访问及传输恢复功能。我们不出售这些数据，不用于广告，不用于训练通用人工智能或机器学习模型，也不会将数据转移给与这些功能无关的第三方。维护者不会查看你的 Google 文件；只有在你明确同意并主动提供数据以解决支持问题、依法必须处理，或为防止滥用和保护安全所必需时，才可能处理你提供的相关数据。

## 保留、删除与撤销授权

本地记录和设置会保留到你删除记录、清除应用数据或卸载应用为止；卸载是否同时清除数据取决于操作系统。未完成传输的暂存文件可能为恢复传输而保留，取消或清理传输时按应用提供的功能删除。

断开云盘账户会删除 SwarmDrop 本机保存的该账户凭证，并尝试撤销 Google 授权。你也可以在 [Google 账户的第三方连接管理](https://myaccount.google.com/connections) 中直接撤销访问权限。撤销授权不会自动删除已经上传到 Drive 的文件。

删除 SwarmDrop 的收件记录不等于删除云盘中的文件。请在 Google Drive 中管理或删除远端文件，并根据需要清空其回收站。

## 官方网站与第三方服务

官网由 GitHub Pages 托管。访问官网、下载 GitHub Release、连接引导或中继服务、以及使用 Google Drive 时，相关服务提供商会接收完成请求所需的网络信息，其处理方式受各自政策约束。你主动提交到 GitHub 的公开 issue 或讨论内容可能公开可见，请勿包含凭证或私密文件。
