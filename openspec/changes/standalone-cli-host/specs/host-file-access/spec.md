## ADDED Requirements

### Requirement: 原生宿主共享同一份本地文件系统实现

面向本地文件系统的 [`FileAccess`] 实现 SHALL 由**所有以本地路径为落点的原生宿主共享的
同一份实现**承担；宿主 SHALL 只提供保存位置，MUST NOT 各自实现读取、暂存与发布。

该共享实现 SHALL 保持既有的全部契约，其中三条尤其不可退让：

- **精确读取**：返回字节数恰为 `min(length, 文件大小 - offset)`，不按任何块尺寸取整。
  取整会直接破坏逐块验签。
- **续传保留**：接上已有暂存时必须保留其已有内容，MUST NOT 截断。截断会产出一个
  长度正确、内容有洞、且完整性判定发现不了的文件。
- **发布不校验**：发布阶段失败意味着「搬不过去」而非「数据损坏」，实现 SHALL 保留暂存。

以非本地路径为落点的宿主（使用系统文档提供方或浏览器存储的那些）不受本要求约束，
它们的落点语义不同，各自实现。

#### Scenario: 桌面与命令行宿主行为一致

- **WHEN** 桌面宿主与命令行宿主各自读取源文件、写入暂存并发布
- **THEN** 两者的读取契约、暂存位置语义与发布行为完全相同

#### Scenario: 宿主只提供保存位置

- **WHEN** 一个新的本地路径宿主接入
- **THEN** 它只需提供保存位置即可获得完整的文件读写行为

#### Scenario: 越界写入被拒绝

- **WHEN** 待写入的相对路径经由符号链接指向保存位置之外
- **THEN** 写入被拒绝，保存位置之外的文件不被触碰

#### Scenario: 浏览器宿主不受影响

- **WHEN** 构建面向浏览器的目标
- **THEN** 该实现不参与编译，浏览器宿主继续使用其自有的存储实现
